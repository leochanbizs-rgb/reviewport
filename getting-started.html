01

IN THE POPUP

Choose and scan

Open a TikTok Shop product page, choose a star range and page limit, then select Scan reviews. Keep Photos only off unless you need only photo reviews.

Exact star scan: set the same minimum and maximum rating. ReviewPort confirms TikTok’s visible filter before it scans.

02

FULL REPORT

Inspect what was saved

When the scan finishes, the full report opens automatically. Sort the table, select any row to read the complete review, and inspect buyer photos without scanning TikTok again.

Need more later? Return to the popup, change the scan settings, and run another scan.

03

EXPORT DRAWER

Choose a file format

Select Export in the report header. Choose Custom CSV for a spreadsheet, LLM Markdown for analysis, or a Shopify review-app format such as Judge.me, Loox, Okendo, Opinew, Ryviu, Yotpo, Stamped, or Fera.

Shopify matching: enter only your own product details when the selected importer requires them. New Shopify exports stay pending by default.

If TikTok asks you to verify

ReviewPort pauses safely. Complete the verification yourself on the TikTok page, then choose Resume after verification in the popup. It never attempts to bypass verification.

Before importing to Shopify

Use the format required by your review app. Some formats need a product handle or product ID. Strict Shopify formats accept public JPG, JPEG, and PNG image URLs; Custom CSV keeps the original captured URLs.

What ReviewPort does not change

ReviewPort keeps TikTok’s original masked username, does not translate or rewrite reviews, does not use external AI services, and does not upload your review data. It only stores saved data locally in Chrome until you export or clear it.

ReviewPort processes saved review data locally in your browser. Not affiliated with TikTok or any Shopify review app.
