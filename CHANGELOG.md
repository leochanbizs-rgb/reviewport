# Changelog

All notable public changes to ReviewPort are recorded here. Versions refer to the `version` field in `manifest.json` and the downloadable GitHub ZIP in this repository.

## v5.4.0

**GitHub ZIP:** [reviewport-v5.4.0.zip](https://github.com/leochanbizs-rgb/reviewport/raw/refs/heads/main/reviewport-v5.4.0.zip)  
**Manifest version:** `5.4.0`

This GitHub-only package updates the extension source and its public documentation. The manifest describes a local scan workflow with pause and stop controls, a limit of up to 100 pages, Review Studio, five-point rating organisation, and local CSV, Markdown, or available Shopify review-app export options. It retains the same requested extension permissions: `activeTab`, `scripting`, `storage`, `alarms`, and TikTok Shop host access.

The repository documentation now identifies GitHub as the only current distribution channel and names `leochanbizs@gmail.com` as the public support contact. ReviewPort remains free and MIT licensed.

## v4.5.0

The previous GitHub ZIP remains in the repository for reference. New installations should use the current v5.4.0 package above.
