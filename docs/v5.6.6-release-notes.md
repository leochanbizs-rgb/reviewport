# ReviewPort v5.6.6

ReviewPort v5.6.6 improves review-response detection, visible-card parsing, pagination safety, exact-rating metric handling, and Review Studio contrast. It retains the same Manifest V3 permissions, TikTok Shop-only host access, local-only storage model, and packaged interceptor boundary as v5.6.1.

## Review collection and exact-rating safety

The packaged interceptor now recognizes TikTok Shop PDP desktop page-data responses as well as bounded review-list paths. Visible review parsing is more defensive about accessible rating labels, separated star glyphs, SVG classes, product labels, dates, and review-card identity.

The exact-rating metrics parser now recognizes TikTok’s full descending `5 → 4 → 3 → 2 → 1` histogram pattern. This avoids treating a count such as `1` as a subsequent rating label and avoids accepting ascending pagination labels as a histogram. It preserves valid zero-result and small single-page metrics, while exact scans still start only when the visible matching-result count numerically equals the requested rating’s visible histogram count.

> An unconfirmed exact rating continues to pause fail-closed. ReviewPort never substitutes an all-review scan.

## Visual accessibility

Review Studio fixes warning-panel text contrast in dark and light themes, corrects light-theme chip text and secondary text contrast, and styles Chrome autofill backgrounds so they follow the selected theme. The CSS audit supplied with this update found no remaining failures across its reviewed text/background pairs.
