# ReviewPort v5.6：精確星等掃描重現報告

## 範圍與方法

本報告以使用者實際提供的 TikTok Shop 截圖、使用者已登入瀏覽器中的公開商品頁，以及同一 PDP 的只讀 HTML 抽取為依據。測試頁為：

`https://shop.tiktok.com/us/pdp/indoor-electric-grill-aoran-kitchen-1000w-non-stick-bbq-with-5-temp-settings/1730975501023219782`

未重複觸發自動掃描、未嘗試繞過驗證、未呼叫非 TikTok 網路服務。

## 實際觀察到的頁面訊號

| UI／來源 | 實際文字或數值 | 意義 |
|---|---|---|
| 中國語系公開 HTML | `全部` | 未篩選 rating 的控制值可呈現為中文 all。 |
| 使用者提供的繁中截圖／規格 | `★ 全部`、`★ 1` | rating 控制值可能有前置裝飾星形，不能以裸文字的行首錨定判斷。 |
| 公開 HTML | `显示 5598 条评价（共 5598 条）` | 目前顯示數與總數都能由同一結果行擷取。 |
| 公開 HTML | `5=4081, 4=416, 3=246, 2=153, 1=702` | 首頁提供完整 histogram；各值相加為 5598。 |
| 公開 HTML | `1 ... 1866 ... 下一步` | 未篩選情況每頁 3 筆（1866 × 3 = 5598）。 |
| 公開 HTML | `商品:` 後接 `Round Large` | 中文 variant label 可能為單獨行或同一行。 |
| 使用者提供的英文 UI／規格 | `Sort by`、`Filter by`、`Item: Round Large` | English UI 的 sort 與 filter 共用短容器，variant label 為 `Item:`。 |
| 使用者提供的單星失敗截圖 | 原生 1 星已選取但 popup 為 0 scanned | 證實單靠 control label／response 接收不足以確認可收集的首批資料。 |

## D-01 至 D-04 核對結果

| ID | 結論 | 證據與處置方向 |
|---|---|---|
| D-01 | **確認** | `normalizedNativeRating()` 對 `全部` 使用行首錨定，無法辨識 `★ 全部`。修正為先剝除首尾星形及空白，再處理 all 與數字。 |
| D-02 | **確認** | 可見卡 parser 的 marker 缺少 `Item`，會令 English UI 的 card parser 失敗。另有 country、multi-paragraph、rendered rating 與 image URL 過濾問題。 |
| D-03 | **確認** | fallback 遍歷所有 `tux-web-select`，shared ancestor 同時含 Sort/Filter 文案時可能先選 Sort。需以可正規化的 rating/all current value 為正向條件並排除 sort label。 |
| D-04 | **確認** | visible fallback 重新呼叫 control-text parser 作 gate；篩選已成功而 control transient re-render 時仍會退回 0。需以數字型結果計數／histogram contract 作主訊號，label 僅做診斷。 |

## 界限與尚待真實 UI fixture 的資料

本環境可讀取繁中公開 HTML；使用者截圖與規格提供 English `Item:`、`Sort by`、`Filter by` 的 UI 證據，但瀏覽器工具無法直接取得 My Browser 中 English dropdown 的 `data-value`／`aria-label` 原始屬性。v5.6 必須保存 fixture（繁中、英文、filter applied、filter not applied、zero result、single page）並以 fixture 測試；若 TikTok 在真實 English UI 的實際 select 屬性與既有規格不同，該屬性值需要補入 fixture 而非猜測。

## 結論

D-01 和 D-02 是目前 0-scanned 問題的直接程式缺陷，應先修正。更根本的 v5.6 確認機制將以首頁 histogram 與結果行的兩個數字為主，只有在 `顯示數 == 所選星等 histogram count` 時才視為精確篩選已套用；label parser 保留為 selector diagnostic，而不再作為唯一真值。
